Overview

Multi-agent invoice approval powered by LangGraph

AI-Powered Approval Pipeline

Intelligent Invoice Processing with Multi-Agent AI

Five specialized agents work together — Extraction, Compliance, Risk, Supervisor, and Reporting — orchestrated by LangGraph with human-in-the-loop approval, persistent vendor memory, and full LangSmith observability.

LedgerLens AI is an AI tool that runs every invoice a business receives against that vendor's actual contract terms and billing history — automatically, before a rupee gets approved. Instead of someone manually cross-checking payment terms, price bands, and prior invoices, five coordinated agents do it in seconds and only pull a human in when something genuinely needs a decision.

How It Works

From first upload to a resolved decision — one pipeline, start to finish

01

Upload the invoice

Open Upload Invoice and add a PDF. It's staged and dropped into New Invoices until a contract is attached to it.

02

Attach the vendor contract

Add that vendor's contract terms — payment terms, price ranges, freeform clauses — so to check the invoices against that vendor contract. Can view added contracts in Added Contracts.

03

Run it through the pipeline

Run a single invoice immediately, or head to New Invoices and select 2–5 contract-ready invoices to run together in batch mode.

04

Review the results

Each invoice's running state through pipeline is shown in Results. Clean invoices under the approval ceiling are auto-approved right there.

05

Resolve anything flagged

An invoice with a compliance miss, a risk signal, or a ceiling breach waits in the Approval Queue — with the reason it was flagged shown alongside it. Approve, reject, or edit and re-validate it from there.

06

Track & report

The Dashboard tallies approved vs. rejected across every invoice. Once a queued invoice is resolved, it moves into All Invoices. Reports covers weekly digests, LLM routing, and evaluations that score processed invoices against vendor contracts.

Core Capabilities

Each agent handles one responsibility — no overlap, no ambiguity

Extraction Agent

Reads any PDF — text-based or scanned — using a 3-tier routing strategy: pdfplumber → Gemini (primary), with automatic Groq fallback.

Compliance Agent

Validates extracted data against vendor contracts using vectorless lookup for exact fields and traditional RAG for freeform clause retrieval.

Risk Agent

Detects duplicates (exact + fuzzy), first-time vendors, and price deviations using persistent vendor history from Supabase.

Supervisor Agent

Makes the final call — auto-approve clean invoices or escalate flagged ones to human review.

Human-in-the-Loop

Graph pauses at the approval node using LangGraph's interrupt(). Humans can approve, reject, or edit fields — edits loop back for re-validation.

Code Guardrails

Hard arithmetic checks (line-item math, total reconciliation, sanity limits) run before any agent sees the data — catches hallucinated numbers early.

Persistent Memory

Every approved invoice is stored in Supabase, building a growing vendor history that makes future risk assessments smarter over time.

Reporting Agent

Independent 5th agent — reads what all others wrote, generates periodic digests with LLM-powered narrative summaries on a configurable schedule.
